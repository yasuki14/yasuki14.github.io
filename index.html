Scorecard Recon

ソフトウェア名を入力すると GitHub 上の該当リポジトリをスター数順に検索し、各リポジトリの OpenSSF Security Scorecard（0〜10点のセキュリティ健全性スコア）を取得して表示します。

>
Enter で検索 / GitHub 検索 API + api.scorecard.dev を使用 scorecard.dev について ↗
データ提供: GitHub REST API / OpenSSF Scorecard REST API（CDLA Permissive 2.0） 認証なしのため GitHub 検索は 10 req/min の制限があります
